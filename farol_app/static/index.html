Agente de programação

  
Descreva o que quer construir. Um arquiteto escreve a especificação, um testador escreve os testes antes do código, o desenvolvedor programa e o Python roda os testes de verdade. Se falhar, o erro real volta para o desenvolvedor corrigir.

  
O código gerado roda no seu computador. O agente só escreve na pasta escolhida e só executa os testes, com limite de 90 segundos. Use uma pasta só para isso. Nesta versão ele gera projetos em Python.

  

    
Quem faz cada papel

    
Com um modelo local, os três papéis usam o mesmo modelo, um de cada vez (cabe em máquinas modestas). Se a máquina for fraca, aponte só o Desenvolvedor para uma API externa compatível com OpenAI.
